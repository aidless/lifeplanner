## 摘要（当前可写的部分）

Q-One 是一个把「万事万物皆可量化」工程化为**可复算测量协议**的个人系统。
核心主张：量化的价值不在数字本身，而在**可证伪性**——一个不可证伪的数字
不是测量，是修辞。系统通过六层架构（量化编译器/证据/计算/决策/不确定性/台账）
把该主张落地，并用三条红线约束自己：不建单一总分、模型不碰算术、
无证据只准拒答。

## 1. 万物量化协议（研究一）

- 量化八元组与五条件（`charter/QUANTIFICATION_PRINCIPLES.md`）
- 已实现：`ontology/measurement_contract.schema.json` + `agent/DECISION_SCHEMA.json`，
  Q-One 输出过 Schema 校验（测试强制）
- 实证发现：
  - CL-01 价值分对 target 极度敏感（0.29→0.73）
  - CL-02 活动量冒充证据（731 次提交撑起 55 分）
  - 两种虚假精确模式及防线（区间 null 规则、实质证据判据）

## 2. 校准型结构化决策 Agent（研究二）

- Laya/Jev 定位：快速结构化决策层（33ms/题），非完整 Agent
- 已实现：三置信度分离（model/evidence/forecast）、拒答门、
  act-or-escalate 路由、决策台账哈希可验伪
- 实测：Laya 路由校准类问题置信 0.9987；enough 门控正确停止收集
- **阴性结果（有价值）**：从零训练的决策头存在内容绑定平台期（CL-04），
  为「Laya 必须建在预训练骨架上」提供机制解释
- 待完成：七级基线 A-G 实测、消融、选项顺序不变性测试

## 3. 与相关工作的差异

| 系统 | 差异 |
|---|---|
| Quantified Self 工具 | 有仪表盘无决策协议；无拒答；无校准 |
| Jev/Laya | 有决策层无「该测什么」的编译器；Q-One 补这一层 |
| 通用 Agent | 无证据分级、无拒答门、数字不可追溯 |

## 4. 局限（诚实声明）

- 单一用户纵向记录，无人类受试实验
- 垂直域仅「项目投入决策」一个
- 校准样本 n=0，所有校准结论标注为演示数据
- LLM 编译器未接入（v2 事项）
