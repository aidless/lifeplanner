# privacy_policy.md · 隐私与数据政策

> 原则：**数据最小化、默认本地、分级授权、可删除、可导出、访问留痕。**

版本：v1（2026-10-22）

---

## 1. 数据分级

| 级 | 内容 | 规则 |
|---|---|---|
| public | 论文矩阵、本体、代码、虚构演示数据 | 可公开（本仓库） |
| private | 观测、指标、目标、决策台账 | 仅本机 SQLite |
| sensitive | 健康、财务、关系、心理 | 仅本机；禁止进入任何外发流程 |
| secret | 密钥、令牌 | 只存 `~/.lifeplan/`，永不入库 |

**sensitive/secret 级数据的唯一出口是用户显式导出的文件。**

## 2. 采集最小化

- 只采集 `life_ontology.yaml` 中已定义九字段的指标；未定义不采集
- 「意义与价值」域只接受偏好声明文本，不产生任何数值
- 不可量化登记表中的对象（职业意义感/关系质量/认知增长）**不采集代理数据**

## 3. 存储与访问

- 唯一存储：`~/.lifeplan/lifeplan.db`（SQLite 单文件）
- 无账号、无遥测、无崩溃上报、无自动更新
- 模型调用（Ollama）走本机 127.0.0.1；**不向任何外部 API 发送个人数据**
  （若用户自行配置远程端点，风险自担，doctor 会显示端点地址）
- 所有写操作（观测/预测/决策/执行）留 `events` 或台账记录

## 4. 用户权利

| 权利 | 实现 |
|---|---|
| 查看 | `lifeplan doctor` / `score` / `report` / `qone list` |
| 修改 | 各子命令直接改；观测可归档不可删（保审计） |
| 删除 | `rm ~/.lifeplan/lifeplan.db`（全删）；或按 id 删单条（留事件痕） |
| 导出 | `lifeplan export` |
| 备份/恢复 | `lifeplan backup` / `restore`（恢复前自动另存） |

## 5. 模型与训练

- **禁止未经允许用个人数据训练任何模型**——包括本项目的 Q-One 决策模型
- 阶段八训练只用 `decisions` 台账中**用户显式标记为可用**的记录
- 模型调用记录不含 sensitive 内容（只有问题类型与工具名）

## 6. 开源发布纪律

推送到公开仓库前必须执行（2026-10-22 已执行三轮）：
1. 扫描个人标识（姓名/城市/真实数值/竞赛名次）
2. 演示数据与真实数据分离（seed 全虚构）
3. 压掉含未清洗数据的 git 历史（orphan 分支首发）
4. clone 回远端 grep 终检

## 7. 高风险领域

医疗、法律、金融、心理危机、重大人生决定：系统只输出
「建议 + 证据 + 不确定性」，并显式提示寻求专业/本人确认，
不得以任何分数形式替代判断。
