# MONTHLY_REVIEW.md · 每月复盘协议

> 蓝图 §11 每月层。回答「目标与指标是否仍然有效」——这是防 Goodhart 的主战场。

版本：v1（2026-10-22）

---

## 流程（月末，约 20 分钟）

```bash
lifeplan report --out reports/monthly-YYYY-MM.md    # 校准摘要在首页
lifeplan audit                                      # 四查自欺
lifeplan qone list                                  # 本月决策台账
```

## 五问（蓝图 §11）

1. 当前目标是否仍然重要？
2. 指标是否仍然代表真实价值？
3. 是否出现长期趋势？
4. 当前资源配置是否合理？
5. 哪些决策已经得到现实验证？

## 第 2 问的操作化（最重要）

对每个指标问三句话：

- **它还在测它声称测的吗？**（构念效度）
- **刷高它的路径是否已经偏离原意？**（Goodhart 检查——
  对照 `FAILURE_LOG.md` 的六模式）
- **有没有更好的代理？**（有则改定义，改则记 `metric_dictionary.md` 版本）

**允许改指标，但不允许悄悄改**：任何指标定义的修改必须记录
新旧版本、修改理由、修改人——这正是基线追认审计在管的事。

## 第 5 问的操作化

台账里 `outcome` 已填的预测，对照当时的 `reason`：
- 当时裁决 `continue` 的，现在看是对的嘛？
- 置信度 `model` 高的判断，比 `evidence` 高的判断更准嘛？
（后者若显著更准，说明该多信任数据少信任模型。）

## 输出

- 月度报告（`reports/monthly-*.md`）
- 指标定义变更记录（如有）
- 下月资源配置调整（权重改动必须主人签）
