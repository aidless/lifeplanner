# WEEKLY_REVIEW.md · 每周复盘协议

> 蓝图 §11 每周层。本文件是 `lifeplan week` 的操作手册与问题清单。

版本：v1（2026-10-22）

---

## 流程（周一 09:30 自动化提醒后执行）

```bash
lifeplan week              # 交互式：结算到期预测 + 补录过期指标 + 归档项
lifeplan calibrate         # 回读：Brier / ECE / 过度自信
lifeplan qone ask "..."    # 需要结构化决策时
```

目标：**≤3 分钟，最多 12 项**。每项都可跳过——跳过是合法操作。

## 六问（蓝图 §11）

1. 本周最重要的结果是什么？
2. 哪些指标发生变化？
3. 哪些行动有效？
4. 哪些时间被低价值活动占用？
5. 下周最值得做的一个实验是什么？
6. 哪个目标应该暂停或调整？

## 复盘必做（蓝图原则六）

```
预测 → 行动 → 观察结果 → 比较预测和现实 → 分析误差 → 更新指标和模型
```

第 5 步「分析误差」必须落到 `outcome_note`：不是记「错了」，
而是记**为什么错**（参考系错/证据不足/执行变形/纯随机）。

## 红线

- 不补记漏掉的观测（记「漏记」）
- 不因为「这周不好看」而改 target——那是基线追认，审计会标 high
- 校准样本 < 5 时，ECE/过度自信只当方向参考，不当结论

## 输出

一次周复产的产物：
- N 条结算预测（带证据等级）
- M 条新观测
- 1 个下周实验（下一条预测）
- 校准曲线更新（`calibrate` 回读）
