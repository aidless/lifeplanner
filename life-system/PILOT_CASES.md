## 案例 1：项目投入决策（垂直域 v1 唯一场景）

### 输入

```
state: "这个项目是否值得继续投入"
```

### 协议展开（量化编译器）

| 题 | 类型 | 内容 |
|---|---|---|
| 投入强度 | measure | 近 30 天 git 提交数（次） |
| 证据密度 | measure | 近 30 天 tier≥2 观测数 |
| 自评准确度 | measure | 1 − \|过度自信度\| |
| 结构完整度 | measure | 有指标目标占比 |
| 价值总评 | measure | 三维加权（0.4/0.3/0.3，权重写进假设） |
| risk | score | 低/中/高/极高（阈值规则文档化） |
| action | choice | continue/pivot/pause/stop/need_data |
| 证据充分性 | noul | 证据是否足以支撑裁决 |

### 首次运行（2026-10-22 23:12，真实库）

```
投入强度 731｜证据密度 0｜自评准确度 None｜结构完整度 0/3
价值总评 55.0 区间[5,100]｜risk 高
action=need_data｜confidence=0.7｜decided_by=abstain
```

### 人工裁决

主人未裁决（等待补证据）。**系统主动拒答被证明是正确的**——
见 F-02：若当时硬答，会得到 `pivot`（活动量冒充证据）。

### 复盘

- 协议正确触发拒答；区间 [5,100] 宽得诚实
- 下一步测量明确：先有 tier≥2 观测与 ≥5 条校准样本
- 待办：等主人提供三个大决策预测的 p 值，让 calibration_n 脱离 0
