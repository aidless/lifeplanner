版本：v1（2026-10-22）

---

## 1. 行动四分类（蓝图 §5.6）

| 类 | 定义 | Q-One 实例 |
|---|---|---|
| 信息行动 | 查资料、做测量、访谈 | `host scan`、`qone ask`、`act tick` |
| 实验行动 | 最小成本验证假设 | 登记一条带 horizon 的预测；`week` 的指标补录 |
| 建设行动 | 持续投入 | 观测记录、目标推进 |
| 退出行动 | 暂停/转向/停止 | 归档指标（`archived`）、目标 status 改 paused |

**规则**：实验行动优先于建设行动——先花最小成本证伪，再谈投入。

## 2. 行动权限 L0-L4（蓝图 §15）

| 级 | 含义 | 本系统实现 |
|---|---|---|
| L0 | 只生成建议 | `qone ask`、`agent ask` 的答复 |
| L1 | 生成草稿或提醒 | `act tick` 的提案、周一自动化的汇报 |
| L2 | 执行可逆操作 | tier0/tier1 工具（只读 / 本地可逆写入） |
| L3 | 执行前必须人工确认 | tier2：`term_exec` / `app_launch`（必须回填令牌） |
| L4 | 禁止自动执行 | sudo、rm -rf、mkfs 等（策略默认拒绝） |

**人生系统默认只允许 L0-L2。** L3 的唯一入口是 `lifeplan act run <id> --confirm-token <token>`。

## 3. 每个行动的必填字段（蓝图 §10 第六步）

```
目标 · 预计收益 · 成本 · 风险 · 预计周期 · 可逆性 · 成功判断标准 · 失败后的下一步
```

实现：提案（Proposal）含 command/rationale/tier；失败后的下一步由
`_next_step()` 按裁决生成。

## 4. 数据权限 P0-P4（蓝图 §15）

| 级 | 内容 | 规则 |
|---|---|---|
| P0 | 公开信息 | 论文矩阵、本体、代码 |
| P1 | 普通个人信息 | 观测、指标、目标 |
| P2 | 敏感个人信息 | 财务细节、投递记录 |
| P3 | 健康/财务/关系/心理 | 仅本机；禁止外发 |
| P4 | 不可自动处理 | 密钥、令牌；永不入库 |

（与 `charter/privacy_policy.md` 的四级制对应：public/private/sensitive/secret。）

## 5. 必须保留的控制（蓝图 §15 八条）

数据可导出 · 数据可删除 · 记忆可修改 · 模型建议可拒绝 ·
价值权重可修改 · 所有行动可回滚 · 所有关键决策可审计 · 模型版本可追踪。

对应实现：`export` / `restore` / 台账 `human_override` / `qone verify` /
`events` 表 / 模型版本记入 `decided_by` 与 README 路由表。
