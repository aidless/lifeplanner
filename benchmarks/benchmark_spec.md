# benchmark_spec.md · 评测规范

> 阶段二的产出。定义「怎么证明系统有用」——在训练任何新模型之前，
> 必须先有这份规范和基线结果。

版本：v1（2026-10-22）

## 1. 基线系统（七级，逐级加能力）

| 级 | 系统 | 考察 |
|---|---|---|
| A | 纯人工判断 | 人的直觉基线 |
| B | LLM 直接回答 | 无工具无协议的裸模型 |
| C | LLM + 工具 | 取证能力 |
| D | LLM + 证据系统 | 可追溯性 |
| E | LLM + Laya/Jev | 决策层贡献 |
| F | LLM + 证据 + 计算器 + Laya/Jev | 完整协议 |
| G | 完整 Q-One | + 拒答门 + 台账 + 复盘闭环 |

**A 是裁判，不是陪跑**：若系统不能稳定超过 A，前面的层都是成本。

## 2. 消融实验（在 F/G 上逐项移除）

| 移除项 | 预期观察 |
|---|---|
| 证据层 | unknown 率下降但错误率上升（开始瞎答） |
| 计算层 | 数值错误率上升（模型算术缺陷暴露） |
| 记忆层 | 跨周一致性下降 |
| Laya/Jev 决策层 | 延迟上升；校准变差（LLM 自评置信不可信） |
| 置信度门控 | 硬答率上升，拒答质量归零 |
| 人工复核 | 高危误执行率上升 |
| 多指标向量 | 诱发单一总分行为 |
| 长期复盘 | 目标-指标漂移无人发现 |

## 3. 任务类型与指标

### 3.1 数值任务（measure/forecast）
MAE、RMSE、MAPE、覆盖率（区间含真值比例）、区间宽度、**区间宽度-覆盖率联合**
（窄而不覆盖 = 虚假精确，一票否决）

### 3.2 分类与决策（choice/score/noul）
Accuracy、Macro-F1、**Brier**、**ECE**（分箱 ≥ 10）、
Risk-Coverage 曲线、**拒答质量**（拒答样本的人工修正率 vs 硬答错误率）

### 3.3 Agent 任务
任务完成率、工具调用成功率、错误恢复率、循环率（同质重试）、
**证据完整度**（有证据的结论占比）、**结果可复现率**（重跑同输入同输出）

### 3.4 人生系统任务（不能只用模型指标）
目标完成率、预测-实际偏差、复盘后决策改善幅度、资源配置效率、
**用户主观负担**（分钟/周）、**指标操纵风险**（Goodhart 触发次数）

## 4. 必须记录的失败类型（doc §13 + RQ6）

| 类型 | 定义 | 记录要求 |
|---|---|---|
| 自信但错误 | 高置信 + 错误 | 逐条入 `FAILURE_LOG.md` |
| 刷高但变差 | 指标涨而参考系指标降 | 跨域审计留痕 |
| 数据缺失的错误推断 | unknown 被硬答 | 拒答门测试 |
| 模型冲突 | 两模型结论相反 | 记录分歧点与最终采信理由 |

## 5. 校准评测细则

- 每题型（choice/score/noul）**分别**算 ECE——不同题型的校准不同
- 选项数量敏感性：3/5/8 选项下准确率与校准的变化
- **选项顺序不变性**：打乱选项顺序，正确答案概率变化 < ε（阶段八测试项）
- 温标重校：留出验证集拟合 T，报告重校前后 ECE（对标 Laya 0.466→0.081）

## 6. 复现要求

每个基线结果必须附：输入快照（脱敏）、随机种子、模型版本、耗时、原始输出 JSON。
`lifeplan qone verify` 校验台账哈希后，结果才可引用。
